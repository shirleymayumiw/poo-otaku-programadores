Aula 01

Classe e objeto: o molde e o herói

A classe é o molde. O objeto é o personagem criado com ele.

class Personagem:
    pass

naruto = Personagem()
sasuke = Personagem()

print(type(naruto).__name__)  # Personagem
Lembrete: uma classe pode criar muitos objetos diferentes.
Aula 02

Atributos: a ficha do personagem

Atributos guardam dados de cada personagem. O método __init__ prepara esses dados quando criamos o objeto.

class Personagem:
    def __init__(self, nome, vida):
        self.nome = nome
        self.vida = vida

naruto = Personagem("Naruto", 100)
print(naruto.nome)  # Naruto
print(naruto.vida)  # 100
self aponta para o próprio objeto. Assim, cada personagem tem sua própria ficha.
Aula 03

Métodos: habilidades especiais

Um método é uma ação definida dentro da classe.

class Personagem:
    def __init__(self, nome):
        self.nome = nome

    def atacar(self):
        print(f"{self.nome} usou um golpe!")

heroi = Personagem("Herói")
heroi.atacar()
Desafio: troque “atacar” por “defender” e mude a mensagem.
Aula 04

Herança: aprender com a classe pai

Uma classe filha pode aproveitar atributos e métodos de uma classe pai.

class Personagem:
    def apresentar(self):
        print("Estou pronto para a batalha!")

class Mago(Personagem):
    def magia(self):
        print("Bola de fogo!")

mago = Mago()
mago.apresentar()
mago.magia()
Aula 05

Polimorfismo: um comando, várias respostas

Objetos diferentes podem responder ao mesmo método de maneiras diferentes.

class Mago:
    def atacar(self):
        print("Lança magia!")

class Guerreiro:
    def atacar(self):
        print("Golpe de espada!")

for heroi in [Mago(), Guerreiro()]:
    heroi.atacar()
Aula 06

Encapsulamento: cuidar dos dados

É uma forma de organizar e controlar o acesso aos dados. Em Python, um atributo com sublinhado, como _vida, sinaliza por convenção que deve ser tratado como interno.

class Personagem:
    def __init__(self, vida):
        self._vida = max(0, vida)

    def receber_dano(self, dano):
        self._vida = max(0, self._vida - dano)

heroi = Personagem(100)
heroi.receber_dano(30)
print(heroi._vida)  # 70

📊 Python para Análise de Dados

Imagine que cada linha de uma tabela é uma missão e cada coluna é uma característica. Nesta trilha você vai aprender a carregar, limpar, analisar e visualizar dados — habilidades usadas em relatórios operacionais, vendas, produtividade e dashboards.

Instalação para praticar no computador: pip install pandas numpy matplotlib openpyxl. Se ainda não puder instalar programas, leia os exemplos e pratique depois no ambiente que sua escola ou trabalho disponibilizar.
Dados 01 · Fundamentos

Variáveis, listas e dicionários

Antes de analisar uma tabela, precisamos guardar informações. Listas guardam vários valores; dicionários guardam pares de chave e valor.

campanha = "PicPay Upgrade"
vendas_por_dia = [12, 15, 9, 18]
operador = {"nome": "Luna", "vendas": 15}

print(sum(vendas_por_dia))  # 54
print(operador["vendas"])  # 15
Desafio: crie uma lista com suas vendas de cinco dias e calcule o total com sum().
Dados 02 · Pandas

DataFrame: uma tabela dentro do Python

A biblioteca pandas facilita trabalhar com dados em linhas e colunas, como uma planilha do Excel.

import pandas as pd

dados = {
    "operador": ["Ana", "Bia", "Caio"],
    "vendas": [12, 8, 15],
    "horas": [6, 5, 7]
}
df = pd.DataFrame(dados)
print(df)
print(df.head())
DataFrame é a tabela; head() mostra as primeiras linhas para uma inspeção rápida.
Dados 03 · Arquivos

Ler CSV e Excel

Dados de relatórios geralmente chegam em CSV ou Excel. O pandas permite carregar os dois formatos.

import pandas as pd

# Arquivo CSV
 df = pd.read_csv("vendas.csv", sep=";", encoding="utf-8")

# Arquivo Excel
# df = pd.read_excel("vendas.xlsx", sheet_name="Base")

print(df.shape)      # linhas e colunas
print(df.columns)    # nomes das colunas
print(df.head())     # primeiras linhas
Se aparecer erro de codificação no CSV, experimente encoding="latin-1" ou confirme se o separador é vírgula ou ponto e vírgula. Remova o espaço antes de df ao copiar o exemplo.
Dados 04 · Limpeza

Tratar dados antes de analisar

Uma análise confiável começa com uma base organizada: nomes de colunas consistentes, duplicidades verificadas e valores ausentes identificados.

# Padronizar nomes das colunas
df.columns = df.columns.str.strip().str.lower().str.replace(" ", "_")

# Conferir valores ausentes
print(df.isna().sum())

# Remover linhas totalmente duplicadas
df = df.drop_duplicates()

# Converter uma coluna para número, se necessário
# df["vendas"] = pd.to_numeric(df["vendas"], errors="coerce")
Não apague valores ausentes automaticamente: primeiro entenda o que significam para o negócio.
Dados 05 · Filtros e métricas

Filtrar, ordenar e criar indicadores

Agora vamos encontrar os melhores resultados e calcular indicadores simples.

# Filtrar operadores com 10 vendas ou mais
melhores = df[df["vendas"] >= 10]

# Ordenar da maior para a menor venda
melhores = melhores.sort_values("vendas", ascending=False)

# Criar uma métrica: vendas por hora
# Evite divisão por zero
df["vendas_por_hora"] = df["vendas"] / df["horas"].replace(0, float("nan"))

print(melhores)
Filtros respondem “quais linhas atendem à regra?”; ordenação responde “qual resultado vem primeiro?”.
Dados 06 · Agrupamento

GroupBy: resumir por campanha, dia ou equipe

O groupby() agrupa linhas e calcula indicadores para cada grupo — como uma tabela dinâmica do Excel.

# Total de vendas por campanha
resumo = df.groupby("campanha", as_index=False)["vendas"].sum()

# Média de vendas por operador em cada campanha
media = df.groupby("campanha")["vendas"].mean()

print(resumo)
print(media)
Troque campanha por uma coluna real da sua base, como ddd, estado, data ou operador.
Dados 07 · Visualização

Transformar números em gráfico

Gráficos ajudam a explicar tendências e comparar resultados. Matplotlib é uma biblioteca comum para começar.

import matplotlib.pyplot as plt

resumo = df.groupby("campanha")["vendas"].sum().sort_values(ascending=False)
resumo.plot(kind="bar", title="Vendas por campanha")
plt.xlabel("Campanha")
plt.ylabel("Vendas")
plt.tight_layout()
plt.show()
Um bom gráfico tem título claro, eixos identificados e responde a uma pergunta específica.
Projeto final · Relatório de vendas

Monte uma análise do começo ao fim

Use uma base autorizada e sem dados pessoais desnecessários. Seu objetivo é criar um resumo que ajude alguém a tomar uma decisão.

  1. Carregue um CSV ou Excel.
  2. Confira colunas, tipos e valores ausentes.
  3. Remova duplicidades somente após validar a regra.
  4. Calcule vendas totais, média e vendas por hora.
  5. Agrupe por campanha ou dia.
  6. Crie um gráfico e exporte o resumo.
