Aula 01

Classe e objeto: o molde e o herói

A classe é o molde. O objeto é o personagem criado com ele.

class Personagem:
    pass

naruto = Personagem()
sasuke = Personagem()
Lembrete: uma classe pode criar muitos objetos diferentes.
Aula 02

Atributos: a ficha do personagem

Atributos guardam dados de cada personagem. O método __init__ prepara esses dados quando criamos o objeto.

class Personagem:
    def __init__(self, nome, vida):
        self.nome = nome
        self.vida = vida

naruto = Personagem("Naruto", 100)
print(naruto.nome)  # Naruto
print(naruto.vida)  # 100
self aponta para o próprio objeto. Assim, cada personagem tem sua própria ficha.
Aula 03

Métodos: habilidades especiais

Um método é uma ação definida dentro da classe.

class Personagem:
    def __init__(self, nome):
        self.nome = nome

    def atacar(self):
        print(f"{self.nome} usou um golpe!")

heroi = Personagem("Herói")
heroi.atacar()
Desafio: troque “atacar” por “defender” e mude a mensagem.
Aula 04

Herança: aprender com a classe pai

Uma classe filha pode aproveitar atributos e métodos de uma classe pai.

class Personagem:
    def apresentar(self):
        print("Estou pronto para a batalha!")

class Mago(Personagem):
    def magia(self):
        print("Bola de fogo!")

mago = Mago()
mago.apresentar()
mago.magia()
Aula 05

Polimorfismo: um comando, várias respostas

Objetos diferentes podem responder ao mesmo método de maneiras diferentes.

class Mago:
    def atacar(self):
        print("Lança magia!")

class Guerreiro:
    def atacar(self):
        print("Golpe de espada!")

for heroi in [Mago(), Guerreiro()]:
    heroi.atacar()
Aula 06

Encapsulamento: cuidar dos dados

É uma forma de organizar e controlar o acesso aos dados. Em Python, um atributo com sublinhado, como _vida, sinaliza por convenção que deve ser tratado como interno.

class Personagem:
    def __init__(self, vida):
        self._vida = max(0, vida)

    def receber_dano(self, dano):
        self._vida = max(0, self._vida - dano)

heroi = Personagem(100)
heroi.receber_dano(30)
print(heroi._vida)  # 70
